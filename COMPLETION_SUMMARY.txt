## 🎯 What It Can Do

### VM Creation Workflow
```
1. User enters: hostname, location, OS, CPU cores, memory, disk, password
2. API validates all inputs
3. Checks Proxmox host availability
4. Allocates IP address from pool
5. Creates database record
6. Authenticates with Proxmox
7. Clones OS template
8. Configures CPU/memory/network
9. Starts VM
10. Updates database with VMID
11. Returns: VM details, IP, hourly cost, status
```

### Power Management
```
1. User selects: action (start/stop/reboot), VM
2. API validates VM exists
3. Gets Proxmox host config
4. Executes action via Proxmox API
5. Waits for completion
6. Updates database status
7. Returns: new status
```

### Options Loading
```
1. Form requests options endpoint
2. API queries: hosts, templates, spec limits
3. Returns: locations, OS options, constraints
4. Form populates dropdowns
```
